COMO USAR (Windows)
===================

1) Instale o Git (uma vez so): https://git-scm.com/download/win
   Pode deixar todas as opcoes padrao do instalador.

2) Crie o repositorio no GitHub (se ainda nao criou):
   github.com/new  ->  nome: clinica-vanessa-alves  ->  Public  ->  sem README  ->  Create repository

3) De dois cliques em  publicar-no-github.bat
   - Na primeira vez ele pede seu nome e e-mail e abre a janela de login do GitHub.
   - Ele envia o site para: https://github.com/VitorTozi/clinica-vanessa-alves

4) Ligue o site (uma vez so):
   No repositorio, va em Settings -> Pages -> Source: "Deploy from a branch"
   -> Branch: main  /  (root)  -> Save.
   Em 1 a 2 minutos o site fica em: https://vitortozi.github.io/clinica-vanessa-alves/

DEPOIS, NO DIA A DIA
- atualizar-e-abrir.bat : baixa a versao mais nova do GitHub para o PC (git pull) e abre o site no navegador.
- publicar-no-github.bat : pede uma descricao, cria uma branch nova, envia para o GitHub e o GitHub
  ABRE UM PULL REQUEST SOZINHO. Voce (ou o Nicolas) revisa e clica em "Merge pull request";
  depois do merge o site atualiza em 1 a 2 minutos.

COMO A EQUIPE TRABALHA (Vitor, Nicolas e Claude)
- Ninguem altera a main direto: toda mudanca vai numa branch e vira um pull request automatico.
- Todo mundo ve o que mudou em "Pull requests", comenta e aprova.
- So o merge na main publica o site.
